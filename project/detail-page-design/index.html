Ampdroid

Author: Lodwick Masete

A lightweight Android server environment for running PHP web applications directly from a mobile device.

Project images

About

Ampdroid brings a local web development environment to Android. The idea is to allow web applications to be developed, tested and hosted locally using a phone instead of a traditional computer.

Technologies

Android PHP Apache PHP-FPM MariaDB

Features

  • Local Apache web server
  • PHP and PHP-FPM support
  • MariaDB database server
  • Local web root for projects
  • Designed for Android devices
  • Run PHP applications locally

Server environment

Web server Apache
PHP PHP-FPM
Database MariaDB
Platform Android

Development

The project focuses on keeping the server environment lightweight while still providing the components normally found in a desktop development stack.
